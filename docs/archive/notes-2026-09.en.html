Revision note — September 2026 report

A record of source-data movement observed after this report was published. English first, then Japanese (site convention). 日本語版は こちら。

The published September 2026 report is a point-in-time snapshot frozen on 2026-09-10, and its content has not been changed. This note records changes MSRC made to the underlying data after that snapshot, using the MSRC CVRF and CISA KEV retrieved on 2026-11-12. The report was correct as a snapshot; the data has since moved.

What this note is

Each monthly report is a frozen snapshot of MSRC primary data taken on a specific day. MSRC revises past months after the fact — adding CVEs, changing severities, and updating exploitation status. The report itself already discloses this and preserves its snapshot values unchanged. This note is the companion record of the movement observed for the September 2026 data after publication, stated as facts. It does not correct or replace the report, and it does not interpret the movement.

Effect on statements in the report

Figures stated in the report that no longer match the upstream data as of 2026-11-12 (each was correct at the freeze). For comparison, the appendix quotes the AI-related credit counts for earlier months (“appeared discontinuously in July, from zero to 39, then once in August”). The July and August counts now stand as follows:

  • July Kugelblitz: frozen 39 → 58 on 2026-11-12 (+19). All 19 added are Microsoft Edge (Chromium-based) advisories (excluded side, Important), first published 2026-07-16 (1: CVE-2026-57980), 07-24 (3: CVE-2026-57978, 57989, 57990) and 07-31 (15: CVE-2026-65802, 65804, 66310, 66311, 66312, 66313, 66314, 66315, 66316, 66317, 66318, 66321, 66322, 66325, 66326). Counting only CVEs first published on or before the July freeze day (2026-07-15) gives 39, matching the frozen value.
  • August Kugelblitz: frozen 1 → 5 on 2026-11-12 (+4). The four added (CVE-2026-66323, 66324, 66798, 70341) are Edge advisories (excluded side, Important), first published 2026-08-28. Counting only CVEs first published on or before the August freeze day (2026-08-13) gives 1, matching the frozen value.

September’s own Kugelblitz count is unchanged: 0 frozen and 0 on 2026-11-12. This note adds no interpretation to these changes.
