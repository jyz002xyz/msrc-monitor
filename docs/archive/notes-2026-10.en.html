The published October 2026 report is a point-in-time snapshot frozen on 2026-10-15, and its content has not been changed. This note records changes MSRC made to the underlying data after that snapshot, using the MSRC CVRF and CISA KEV retrieved on 2026-11-12. The report was correct as a snapshot; the data has since moved.

What this note is

Each monthly report is a frozen snapshot of MSRC primary data taken on a specific day. MSRC revises past months after the fact — adding CVEs, changing severities, and updating exploitation status. The report itself already discloses this and preserves its snapshot values unchanged. This note is the companion record of the movement observed for the October 2026 data after publication, stated as facts. It does not correct or replace the report, and it does not interpret the movement.
