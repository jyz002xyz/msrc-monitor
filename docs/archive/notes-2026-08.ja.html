公開済みの2026年8月レポートは 2026-08-13 時点で凍結した時点スナップショットであり、内容は一切変更していない。本ノートは、そのスナップショット取得後に MSRC が元データに加えた変動を、2026-11-12 に取得した MSRC の CVRF と CISA KEV をもとに記録するものである。レポートはスナップショットとして正しく、その後にデータが動いた、という位置づけである。

このノートの位置づけ

各月次レポートは、特定日に取得した MSRC 一次データの凍結スナップショットである。MSRC は過去月を事後改訂する — CVE の追加、深刻度の変更、悪用状況の更新など。レポート本文はこの性質を既に開示し、スナップショット値を変更せず保持している。本ノートは、公開後に観測された2026年8月データの変動を事実として記録する補助資料であり、レポートを訂正・置換するものではない。変動の意味は解釈しない。

CVE-2026-65660（SharePoint）— KEV と CVRF の悪用フラグの食い違い

  • MSRC の改訂文（CVRF の RevisionHistory、版 1.2、2026-09-25）: “As of 9/25/2026, Microsoft had reliable evidence of observed attacks against exploitation of this vulnerability.”
  • CISA KEV: 2026-09-25 に収載。
  • CVRF の悪用フラグ: 2026-11-12 の時点で Exploited:No（Publicly Disclosed:No）。
  • EPSS: 0.0985（2026-11-10）。

改訂文と KEV は悪用に触れているが、悪用フラグは No のままである。どちらが正しいかは、本ノートでは判断しない。凍結の時点（2026-08-13）では KEV に載っておらず、改訂文もまだ無かった。

レポート内の記述への影響

本文に書いた事実や数のうち、2026-11-12 時点の上流のデータと合わなくなったもの（いずれも凍結の時点では正しい）:

  • 補遺「今月の Kugelblitz は1件である」→ 2026-11-12 は 5件。増えた4件（CVE-2026-66323・66324・66798・70341）はすべて Edge の勧告（除外の側、Important）で、初版は 2026-08-28（凍結の15日後）。凍結の後に加わった勧告で、既存の CVE の謝辞が書き換わったものではない。初版が凍結の日以前の CVE だけで数えると 1 になり、凍結値と一致する。5件とも Critical ではない。
  • 補遺「その Edge 勧告自体が今月は前月の1割以下に減っている」→ 初版が各月の凍結の日以前の Edge の勧告で数えると、8月 39件・7月 475件（8.2%）で、凍結の時点では正しい。2026-11-12 は 8月 362件・7月 936件（38.7%）である。どちらの月も、凍結の後に Edge の勧告が加わった。
  • 図3（Kugelblitz）の8月の点（1）と、その解釈「7月に突出した後、今月は1件へ戻った」→ 2026-11-12 は 5件。7月の点（39）も、2026-11-12 では 58 である（7月号の改訂ノートの 2026-11-12 追記を参照）。
  • 補遺「AIフィジカルインターフェイス二号機」13件 → 2026-11-12 は 16件。16件とも初版が凍結の日以前の CVE で、凍結の後に謝辞が書き換わった形である。凍結時の CVRF の写しが無いため、どの3件かは特定できない（凍結の後に謝辞の更新が記録された該当 CVE は5件）。“AI’s physical interface 001” の1件は変わらない。
  • ゼロデイ: 公開済みが2件から3件になった（CVE-2026-69414、Microsoft Defender の権限昇格、Important。初版 2026-08-14、凍結の翌日）。悪用確認は CVE-2026-68820 の1件のままである。

本ノートは、これらの数の変化に解釈を加えない。本文の「この減少は解釈できない」にも何も足さない。
